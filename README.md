# 科學閱讀陪練

靈感來自 Google NotebookLM，但底層是 **實證研究驗證的學習方法組合**。

## 用法

**Kimi Work（推薦）**：已內建為 skill，直接把書丟給 agent 說「帶我讀這本書」即可。進度自動存盤，還會建立每天檢查到期的跨天複習定時任務。

**其他 agent**：

1. 把 `PROMPT.md` 的完整內容丟給 agent
2. 同時丟一本書給 ta（書名/作者、PDF、或整段文字）
3. Agent 會掃描全書 → 產出知識地圖 → 5 題快速測判斷你的起點 → 從最適合的難度開始
4. 每個概念走 PQ4R 循環：預覽 → 提問 → 精讀 → 反思 → 你費曼回去 → 複習

> `SKILL.md` 是主版本（Kimi Work skill 格式，含跨天複習調度）；`PROMPT.md` 是與之同步的便攜版，給任意 agent 使用。

## 底層方法論（基於 Dunlosky 2013 元分析 + 後續認知科學研究）

| 方法 | 證據等級 | 說明 |
| --- | --- | --- |
| 主動回憶 / 檢索練習 | 🔴 高效 | 提問 > 被動聽解，自測比重複閱讀效果好得多 |
| 間隔重複 | 🔴 高效 | 雙層排程：會話內 1-3-7 輪 + 跨天 1-3-7-30 天，對抗遺忘曲線 |
| PQ4R 閱讀框架 | 🟡 中效 | Preview-Question-Read-Reflect-Recite-Review，結構化閱讀流程 |
| 費曼技巧 / 自我解釋 | 🟡 中效 | 用大白話說出來檢驗理解，發現知識缺口 |
| 精細提問 | 🟡 中效 | 不斷問「為什麼」，加深知識聯結 |
| 交錯練習 | 🟡 中高效 | 混合不同概念複習，辨別力 +25% |

> ⚠️ 常見的「學習金字塔」（聽講5%、教別人90%）的具體數字是 **偽科學**，沒有實證來源。但「主動學習 > 被動學習」的方向是正確的。

## 核心特色

| 特色 | 說明 |
| --- | --- |
| PQ4R 循環 | 六步結構化流程，不跳步 |
| 階梯式難度 | L1（一句話秒懂）→ L5（深度思辨），每級有錨點示例校準 |
| 明確起點判定 | 5 題快速測 + 評分標準，0-1 分從 L1 開始，4-5 分直接進 L4-L5 |
| 費曼檢驗 | 你「聽懂了」不算，要能自己說出來才算過 |
| 雙層間隔複習 | 會話內 1-3-7 輪鞏固 + 跨天 1-3-7-30 天排程，學完不忘 |
| 交錯提問 | 複習時混合 2-3 個舊概念，提升辨別力 |
| 雙模式 | 主動引導 + 自由問答，你問就答，答完拉回進度 |
| 知識地圖 | 視覺化追蹤已掌握 / 待複習 / 未接觸，持久化到本地文件 |
| 跨天複習任務 | Kimi Work 環境自動建立定時任務，每天檢查到期複習並主動考你 |

## 難度等級

- **L1** 一句話秒懂 — 日常經驗就能理解
- **L2** 稍微想一想 — 需要新視角，不需要前置知識
- **L3** 需要理解 — 要把幾個概念串起來
- **L4** 深入分析 — 核心論證或複雜模型
- **L5** 深度思辨 — 挑戰觀點、跨界對比、批判性思考

## 雙層間隔複習排程

```
【會話內】概念首次掌握 → 1 輪後複習 → 3 輪後 → 7 輪後
（一輪 = 學完一個新概念；任何一次答錯 → 重置從 1 輪開始）

【跨天】會話內鞏固完成 → 1 天後 → 3 天後 → 7 天後 → 30 天後
（任何一次答錯 → 重置從 1 天後開始；全部通過 → 🟢 長期掌握）
```

## 適合什麼書

任何你想「真正理解」而非「翻過就好」的書：

- 商業思維類（《原子習慣》《窮查理的普通常識》）
- 技術類（《程式碼大全》《設計模式》）
- 科普類（《時間簡史》《人類大歷史》）
- 哲學類（《沉思錄》《存在主義》）
